# Charts

Live TradingView charts for BTC/ZAR and ETH/ZAR, made to live on an iPhone home screen.

- Open https://waldo881.github.io/charts/ in Safari, tap Share → **Add to Home Screen**.
- Toggle BTC/ETH, ZAR/USD and 1D/4h/1h. Choices are remembered.
- **Trading Desk** opens the journal, weekly prep and coach. **Luno** opens the exchange.

Charts come from TradingView's free widget. The rand feed can differ slightly from Luno's price, so check Luno before placing an order.
